수업 개설

같은 HTML에서 교사와 학생이 각자 역할을 선택합니다. 학습 시작 전 모둠마다 지도에서 지역을 선택합니다.
Supabase 실시간 연동 · 6개 모둠, 학생 수 제한 없음
교사와 학생이 각자 스마트폰·노트북에서 동일한 웹 주소로 접속합니다. Realtime 변경 알림 후 최신 정보 재조회, 7초 보정 조회 및 연결 복구 시 자동 동기화를 지원합니다. 교사는 경매를 제어하고 학생은 공동 계획과 개인 성찰에 참여합니다.
같은 코드를 입력하면 기존 수업의 진행 단계와 기록을 불러옵니다. 새 수업은 사용하지 않은 코드를 입력하세요. 기존 수업을 새 활동으로 바꾸려면 교사 화면에서 전체 초기화를 실행합니다. 교사 인증은 Supabase 계정으로 관리하며 비밀번호는 이 HTML 파일에 저장되지 않습니다.
